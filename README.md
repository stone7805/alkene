# 烯烃四类通关游戏 V2.1

面向高职有机化学初学者的四关网页游戏。单文件 `index.html` 内含页面、题库、判定、声音与打印样式；无外部脚本或字体。12份档案合计100分，答错只记录正式尝试，关尾错题独立重练后才能解锁下一关和最终成绩单。

## GitHub Pages 发布

方案 A：在新建的公开仓库根目录上传本包解压后的 `index.html`、`.nojekyll`，于 Settings → Pages 选择 `main` 与 `/(root)`。打开 Pages 设置中的实际网址；通常为 `https://用户名.github.io/仓库名/`。

方案 B：在已启用 Pages 的仓库中创建独立的 `alkene/` 目录，把 `index.html` 放入该目录。访问 `https://用户名.github.io/仓库名/alkene/`。如果宿主仓库有根目录 service worker，须核对其导航缓存不会把子目录页面覆盖；本包不自带 service worker。

上传完成后，用手机实际打开网页，走一条答错→纠正→关尾重练路径，刷新检查进度；通关后检查成绩单与 A4 打印预览。二维码应指向最终 HTTPS 网页，不要指向 ZIP 下载地址或 GitHub 的 blob 文件页。

## 记录与隐私

身份、尝试、成绩仅保存在学生所用浏览器的本地存储中。更换设备、浏览器或清除网站数据不会自动同步。GitHub Pages 只发布静态页面，不会自动回传智慧职教或生成防篡改成绩；不要把真实学生名单和成绩上传到仓库。若用于正式考核，应另接服务器身份、时间与签名成绩。

版本 V2.1；存档键与 V2.0 独立。旧版进度仍需在 V2.0 文件或原网址中查看。
