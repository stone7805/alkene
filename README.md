# 烯烃四类通关游戏 V3.0

## 更新 GitHub Pages

将本压缩包中的 `index.html` 和 `legacy-v2.4.html` 上传到 `stone7805/alkene` 仓库根目录；`.nojekyll` 与 `README.md` 可同时上传。替换原来的根目录 `index.html` 后等待 Pages 部署，打开 https://stone7805.github.io/alkene/ 查看标题与页脚是否为 V3.0。网址不变，原二维码仍有效。

不要把压缩包本身作为网页文件直接上传；需要解压后上传 `index.html`。

## 本版学习路径

- 命名侦探 20 分（4 题）、结构简式工厂 25 分（3 题）、异构体工坊 25 分（3 题）、溴水证据鉴别室 30 分（3 题），共 13 题 100 分。
- 每关正式题全通过后，曾正式答错的题必须用新题做关尾变式；待练项清空后才能解锁下一关。正式分与正式尝试不因变式改变。
- 第四关分别运行 A/B 组，只改一组时仅使该组旧观察失效；基础结论和证据边界分两步回答。
- 详细学习记录需学生主动下载 20 列 CSV 或复制 JSON 私下交老师；静态 GitHub Pages 不自动上传成绩。
- V2.4 的本机记录保存在旧版键中；因新版题目和分值重排，不把它转换成 V3.0 成绩。旧版查看入口位于 `legacy-v2.4.html`，与新版同域时能读取原浏览器的旧进度。
- 离线打开 `index.html` 可正常游戏；GitHub Pages 上首次打开仍需网络。页面适配手机/电脑及 A4 打印样式，部署后应在班级常用手机和打印机上实际核对。
- 本机成绩和核验码并非服务器签名，可被设备使用者修改；换设备或清除网站数据后无法自动恢复。
