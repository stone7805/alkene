# 烯烃四类通关游戏 V2.2

这是单文件离线网页游戏，也可通过 GitHub Pages 在手机和电脑上访问。

## 更新现有网站

1. 解压后，把 `index.html` 上传到 `stone7805/alkene` 仓库的根目录，替换旧 `index.html`。
2. 若根目录没有 `.nojekyll`，可一并上传本包中的同名文件。`README.md` 仅是说明，不影响运行。
3. 等待 GitHub Pages 部署完成，访问 https://stone7805.github.io/alkene/ 核对页脚为 V2.2。
4. 二维码仅编码上述网址，地址不变时可以继续扫码，但旧二维码图片上的 V2.1 文字已过时。

不要只上传名称含 V2.2 的 HTML 文件而遗漏根目录 `index.html`，否则网站仍会打开旧版。

## 本版

- 每关正式任务完成后，错题在本关关尾独立必修重练；本关待练项清空才解锁下一关。
- 第四关“未明显褪色”选项改为通顺的中文，仍保留证据结论的边界。
- 修正更换时区或跨夏令时后，完成时间记录可能被误判为损坏的问题；报告明确显示必修错题已完成与正式总分。
- 同一浏览器来源的 V2.1 存档会尝试安全接续，旧版存档不会删除；无效的新版本记录会先保留本机异常备份。浏览器本地成绩不可作为正式防篡改凭证。
