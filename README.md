# 烯烃四类通关游戏 V2.4

这是单文件离线网页游戏，可通过 GitHub Pages 在手机和电脑上访问。

## 更新现有网站

1. 解压后，把 `index.html` 上传到 `stone7805/alkene` 仓库根目录，替换旧 `index.html`。
2. 等待 GitHub Pages 部署完成，访问 https://stone7805.github.io/alkene/ 核对页脚为 V2.4。
3. 网址没有改变时，原二维码仍然有效；二维码编码的是网址，不是网页版本号。

不要只上传名称含 V2.4 的 HTML 文件而遗漏根目录 `index.html`，否则网站仍会打开旧版。

## 本版更新

- 所有成绩入口都使用醒目的红色加粗显示：顶部正式得分、通关页正式得分、成绩单总分、逐题得分、分关得分和完成状态；打印版同样保留红色。
- 每关正式任务完成后，错题在本关关尾独立必修重练；本关待练项清空才解锁下一关。
- 第四关终局中，“褪色支持样品含可与 Br₂ 加成的碳碳双键”属于科学上正确的基础判断；“混合物含烯烃，不能据此定量组成”是更完整的判断，两者均可通过，反馈会提示完整表达。
- 保持10位阿拉伯数字学号、身份锁定、单页成绩单、错题完成后打印等约束。
- 浏览器本地成绩仅用于课堂练习，不是服务器签名的正式考试凭证。
