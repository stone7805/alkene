# 烯烃四类通关游戏 V3.1

## 更新 GitHub Pages

1. 解压本压缩包。
2. 将包内的 `index.html`、`legacy-v2.4.html`、`.nojekyll` 和 `README.md` 上传到 `stone7805/alkene` 仓库根目录。
3. 用新的 `index.html` 覆盖旧文件，等待 GitHub Pages 部署。
4. 打开 https://stone7805.github.io/alkene/，确认页面标题与页脚显示 V3.1。

网址保持不变，原二维码继续有效。不要把 ZIP 文件本身当作网页上传。

## V3.1 修正

- 第 3 关任务“区分位置异构”把“另一种双键位置”显示为红色粗体提示。
- 结构题卡和选择按钮只显示一组 A/B/C/D 编号，例如 `A · CH₂=CH—CH₂—CH₃`。
- 同一浏览器、同一网址中的 V3.0 进度会自动复制到 V3.1 记录键；正式得分、错题状态、重练状态和已封存成绩保持不变。

## 本版学习路径

- 命名侦探 20 分（4 题）、结构简式工厂 25 分（3 题）、异构体工坊 25 分（3 题）、溴水证据鉴别室 30 分（3 题），共 13 题 100 分。
- 每关正式题全通过后，曾正式答错的题必须用新题做关尾变式；待练项清空后才能解锁下一关。正式分与正式尝试不因变式改变。
- 第四关分别运行 A/B 组，只改一组时仅使该组旧观察失效；基础结论和证据边界分两步回答。
- 详细学习记录需学生主动下载 20 列 CSV 或复制 JSON 私下交老师；静态 GitHub Pages 不自动上传成绩。
- V2.4 记录仍可通过 `legacy-v2.4.html` 查看。
- 离线打开 `index.html` 可正常游戏；页面适配手机、电脑及 A4 打印。
- 本机成绩和核验码并非服务器签名；换设备或清除网站数据后无法自动恢复。
